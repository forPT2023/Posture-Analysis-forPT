頸部測定機能の確認手順

v13.0.0 - 頸部機能評価モードの使用ガイド

⚠️ 重要な確認事項 頸部測定機能は実装済みです。もし表示されない場合は、ブラウザのキャッシュが原因です。以下の手順で必ず表示されます。

📱 ステップ1: ブラウザキャッシュのクリア

1
スーパーリロードを実行
Windows/Linux: Ctrl + Shift + R
Mac: Cmd + Shift + R
iPhone/iPad: 設定 → Safari → 履歴とWebサイトデータを消去
通常のリロード（F5やCmd+R）では、キャッシュされた古いファイルが読み込まれます。必ずスーパーリロードを実行してください。
2
開発者ツールでキャッシュ無効化（推奨）
Chrome/Edge:
1. F12キーで開発者ツールを開く
2. ネットワークタブを選択
3. 「キャッシュを無効にする」にチェック
4. ページをリロード

🎯 ステップ2: 矢状面モードの選択

1
「矢状面（側面）」を選択
アプリの左サイドバーにある「撮影面の選択」で
矢状面（側面）のラジオボタンをクリック
説明文: "横から撮影（頸部機能評価・前後姿勢分析）"
2
矢状面分析設定パネルの表示確認
矢状面を選択すると、すぐ下に「矢状面分析設定」パネルが表示されます。
表示される内容：

📏 矢状面分析設定

ℹ️ 頸部機能評価
以下のオプションから測定したい項目を選択してください。
✓ アライメント評価: 頭部の前方偏位を測定
✓ 後屈可動域測定: 頸部の伸展角度を測定

⚙️ ステップ3: 測定モードの選択

1
撮影側面を選択
ラジオボタンで「左側面」または「右側面」を選択
デフォルト: 右側面
2
測定モードのチェックボックスをON
以下のチェックボックスから測定したい項目を選択：
  • アライメント評価 - 頭部前方偏位の評価（耳-肩の位置関係）
  • 後屈可動域測定 - 頸部の伸展角度測定（耳-目の角度）
重要: チェックボックスをONにしないと、測定が実行されません。両方同時に選択することも可能です。

🚀 ステップ4: 分析の実行

1
施術前後の写真をアップロード
Before（施術前）とAfter（施術後）の側面写真をそれぞれアップロード
2
「姿勢を分析」ボタンをクリック
分析が開始され、結果が表示されます
3
測定結果の確認
アライメント評価を選択した場合:
• 頭部前方偏位角度（度）
• 頭部前方偏位距離（mm）
• 評価: 正常 / 軽度 / 中等度 / 重度

後屈可動域測定を選択した場合:
• 頸部後屈可動域（度）
• 正常可動域との差（度）
• 評価: 正常可動域 / 軽度制限 / 中等度制限 / 重度制限
改善した項目には ✅改善 バッジが表示されます

🔍 トラブルシューティング

Q
矢状面分析設定パネルが表示されない
原因: ブラウザキャッシュが原因
解決策: スーパーリロード（Ctrl+Shift+R / Cmd+Shift+R）を実行
Q
測定結果に頸部の項目が表示されない
原因: チェックボックスがOFFのまま
解決策: 「アライメント評価」または「後屈可動域測定」のチェックボックスをONにする
Q
「正常」「軽度」などのステータスが表示されない
原因: 古いバージョンが読み込まれている
解決策: 開発者ツールでキャッシュを無効化してリロード
