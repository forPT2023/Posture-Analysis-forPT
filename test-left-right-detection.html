📋 テスト手順

🧪 テスト1: 左側面の測定精度
  1. アプリを開き、開発者コンソールを開く（F12キー）
  2. 「矢状面（側面）」を選択
  3. 「頸部専用評価」を選択（アライメント評価が自動ON）
  4. Before画像: 左側面の姿勢画像をアップロード
  5. After画像: 左側面の異なる姿勢画像をアップロード
  6. 「姿勢を分析」ボタンをクリック
  7. コンソールログを確認
  8. 表示された数値データを記録

📊 期待される結果（左側面）

✅ Before画像の分析完了: { imageId: "1234567890_0.123", ear: "(0.512, 0.234)" } ✅ After画像の分析完了: { imageId: "1234567891_0.456", ear: "(0.498, 0.245)" ← 異なる座標 } 🔍 サイド判定: { before: 'left', after: 'left' } 🔍 Before座標: { ear: "(0.512, 0.234)", shoulder: "(0.534, 0.456)" } 🔍 After座標: { ear: "(0.498, 0.245)", shoulder: "(0.521, 0.467)" } 🔍 計算結果: { beforeAngle: "24.9", afterAngle: "18.5", ← 異なる角度 beforeDistance: "33.2", afterDistance: "28.1" ← 異なる距離 }

画面表示: 頭部前方偏位角度: 24.9 → 18.5 度 ✓ 改善

🧪 テスト2: 右側面の測定精度
  1. ページをリロード（キャッシュクリア: Ctrl+Shift+R）
  2. 同じ設定（矢状面 → 頸部専用評価）
  3. Before画像: 右側面の姿勢画像をアップロード
  4. After画像: 右側面の異なる姿勢画像をアップロード
  5. 「姿勢を分析」ボタンをクリック
  6. コンソールログを確認
  7. 表示された数値データを記録

📊 期待される結果（右側面）

🔍 サイド判定: { before: 'right', after: 'right' } 🔍 Before座標: { ear: "(0.488, 0.256)", shoulder: "(0.466, 0.478)" } 🔍 After座標: { ear: "(0.502, 0.267)", shoulder: "(0.479, 0.489)" } 🔍 計算結果: { beforeAngle: "26.3", afterAngle: "19.2", ← 異なる角度 beforeDistance: "31.8", afterDistance: "26.5" ← 異なる距離 }

画面表示: 頭部前方偏位角度: 26.3 → 19.2 度 ✓ 改善

🧪 テスト3: 左右混在（クロステスト）
  1. ページをリロード
  2. Before画像: 左側面の姿勢画像
  3. After画像: 右側面の姿勢画像
  4. 分析実行してコンソール確認

✓ 検証チェックリスト

1. 左側面のBefore/Afterで異なる数値が表示される

3. コンソールログでサイド判定が正しく表示される

🔍 サイド判定: { before: 'left/right', after: 'left/right' }

4. Before座標とAfter座標が異なる値を持つ

コンソールの 🔍 Before座標 と 🔍 After座標 が異なる

5. 改善がある場合、✓ 改善マークが表示される

角度や距離が小さくなった場合に改善バッジが表示

6. 左右混在でも正しく動作する

Before左、After右でも各々正しいランドマークを使用

7. 描画されるマーカー位置が正しい

耳と肩のマーカーが画像上の正しい位置に表示される

⚠️ トラブルシューティング

問題: 数値がまだ同じ

→ ブラウザキャッシュをクリア
→ 完全リロード: Ctrl+Shift+R
→ シークレットモードで開く

問題: サイド判定が wrong

→ 画像が全身を含んでいるか確認
→ 肩がはっきり写っているか確認
→ 左右どちら向きか再確認

問題: コンソールログが出ない

→ F12キーで開発者ツールを開く
→ 「Console」タブを選択
→ ページをリロードしてから再試行
