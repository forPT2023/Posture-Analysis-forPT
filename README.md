# 姿勢分析ツール v1.0

整体院・治療院向けの、施術前後の姿勢を比較分析するWebアプリケーションです。AI（MediaPipe Pose）を使って骨格を自動検出し、Before/Afterの変化を視覚的に表示します。

## 🎯 主な特徴

- **AI姿勢検出**: Googleの最新AI（MediaPipe Pose）で33個の関節点を自動検出
- **Before/After比較**: 施術前後の画像を左右または上下に並べて比較
- **骨格線の可視化**: 関節を線で結んで姿勢の変化を明確に表示
- **数値データ表示**: 肩の高さ差、骨盤の傾き、体幹の傾きなどを数値で表示
- **変化ハイライト**: 変化が大きい部分を色で強調表示（緑→黄→赤）
- **カスタマイズ可能**: 線の太さ、色、レイアウトを自由に調整
- **データ保存機能**: 作業内容をJSON形式で保存・読み込み
- **高品質エクスポート**: PDF/PNG/JPG形式でA4横向きに出力
- **完全オフライン**: ブラウザ内で全処理が完結（画像はサーバーに送信されません）
- **マルチデバイス対応**: デスクトップ/タブレット/スマホ完全対応

## ✨ 主要機能

### 1. **撮影面の選択**
- **前額面（正面）**: 左右の高さ比較に最適
- **矢状面（横）**: 前後の姿勢・可動域分析に最適

### 2. **画像アップロード**
- Before（施術前）とAfter（施術後）の2枚の画像をアップロード
- デスクトップ: ファイル選択
- モバイル/タブレット: カメラ撮影またはファイル選択
- 対応形式: JPG、PNG、GIF

### 3. **AI姿勢分析**
- MediaPipe Poseで全身の骨格を自動検出
- 33個の関節点（頭部、肩、肘、手首、骨盤、膝、足首など）
- 人物が全身写っていれば高精度で検出

### 4. **表示設定**
- **レイアウト**: 左右並列 or 上下配置
- **骨格線**: 表示/非表示切り替え
- **数値データ**: 表示/非表示切り替え
- **変化ハイライト**: 表示/非表示切り替え
- **線の太さ**: 1px〜6px（スライダーで調整）
- **Before色**: 青、緑、紫、オレンジから選択（デフォルト: 青）
- **After色**: 赤、ピンク、オレンジ、黄色から選択（デフォルト: 赤）

### 5. **数値データ表示**
分析結果として以下の数値を自動計算：
- **肩の高さ差**: 左右の肩の高さの差（mm単位）
- **骨盤の傾き**: 左右の骨盤の傾き角度（度単位）
- **体幹の傾き**: 肩と骨盤の中点を結ぶ線の傾き（度単位）
- **頭部の位置**: 肩中心からの水平距離（mm単位）

各項目に「改善」または「変化」のステータスが表示されます。

### 6. **変化ハイライト**
関節の移動距離に応じて色分け表示：
- 🟢 **緑**: 変化小（0〜2cm）
- 🟡 **黄色**: 変化中（2〜5cm）
- 🔴 **赤**: 変化大（5cm以上）

### 7. **データ保存・読み込み**
- **保存**: 画像、分析結果、設定をJSON形式で保存
- **読み込み**: 保存したデータから状態を完全復元
- 使用例: 作業を中断して後で続きから再開、施術記録の保管

### 8. **エクスポート**
- **PDF**: 印刷に最適（A4横向き、高解像度）
- **PNG**: 透明背景対応の画像形式
- **JPG**: 汎用性の高い画像形式

## 🚀 使い方

### Step 1: 撮影面を選択
1. **前額面（正面）**: 患者さんを正面から撮影する場合
2. **矢状面（横）**: 患者さんを真横から撮影する場合

### Step 2: 画像をアップロード
1. 「Before（施術前）」の画像をアップロード
2. 「After（施術後）」の画像をアップロード

**📸 撮影のコツ:**
- 人物が**全身写っている**ことが重要
- 背景はシンプルな方が検出精度が高い
- 前額面なら**正面から**、矢状面なら**真横から**撮影
- 照明は明るく、影が少ない方が良い

### Step 3: 姿勢を分析
1. 「姿勢を分析」ボタンをクリック
2. AIが自動的に骨格を検出（数秒〜10秒程度）
3. 分析結果がプレビューエリアに表示される

**⚠️ エラーが出た場合:**
- 人物が全身写っているか確認
- 画像が明るく、ピントが合っているか確認
- 前額面/矢状面の選択が正しいか確認

### Step 4: 表示をカスタマイズ（任意）
- レイアウトを変更（左右 or 上下）
- 骨格線の太さや色を調整
- 数値データやハイライトの表示/非表示を切り替え
- 「表示を更新」ボタンで反映

### Step 5: エクスポート
1. 患者さんに見せる場合: そのままプレビューを表示
2. 印刷する場合: 「PDFでダウンロード」
3. データで送る場合: 「PNGでダウンロード」または「JPGでダウンロード」

## 💡 使用上のヒント

### デスクトップ
- 高解像度の画像を使用すると分析精度が向上します
- 分析には数秒かかります（画像サイズによる）
- 複数のパターンを試して最適な設定を見つけてください

### スマホ・タブレット
- カメラで直接撮影できます（「カメラで撮影」を選択）
- 撮影時は三脚を使うと安定します
- 分析結果をその場で患者さんに見せることができます

### 整体院での活用例
1. **施術前**: 患者さんの姿勢を撮影
2. **施術後**: 同じ角度・位置から再度撮影
3. **分析**: このアプリで骨格を検出・比較
4. **説明**: 変化を視覚的に説明（数値データも活用）
5. **記録**: データを保存して施術記録として保管
6. **配布**: PDFで出力して患者さんに渡す

## 🔒 プライバシー

- すべての処理はブラウザ内で完結
- アップロードした画像はサーバーに送信されません
- 個人情報は一切保存されません（ローカルに保存したJSONファイルは除く）
- MediaPipe PoseのAIモデルはCDNから読み込みますが、画像データは送信されません

## ⚠️ 注意事項

### 推奨環境
- **ブラウザ**: Chrome、Firefox、Safari、Edge（最新版）
- **インターネット接続**: 必要（MediaPipe PoseのCDN読み込みのため）
- **画像サイズ**: 1080p〜2K程度を推奨（高すぎると処理が遅くなる）

### 制限事項
- 人物が全身写っていない場合、検出精度が低下します
- 複数人が写っている場合、正しく検出できない場合があります
- 極端に暗い画像や逆光の画像は検出できない場合があります
- 医療診断目的での使用は推奨しません（あくまで視覚的な比較ツールです）

## 🔧 トラブルシューティング

### 「姿勢を検出できませんでした」と表示される
- **原因**: 人物が全身写っていない、背景が複雑、画像が不鮮明
- **対策**: 
  - 人物が画面の中央に全身写るように撮影し直す
  - 背景をシンプルにする（白い壁など）
  - 照明を明るくする

### 分析が遅い
- **原因**: 画像サイズが大きすぎる、デバイスの性能不足
- **対策**:
  - 画像を1080p程度にリサイズする
  - 他のタブやアプリを閉じる
  - デスクトップPCを使用する

### 骨格線がずれている
- **原因**: 服で関節が隠れている、画質が悪い
- **対策**:
  - 体のラインが分かりやすい服装で撮影
  - 高画質で撮影する
  - 照明を改善する

### エクスポートできない
- **原因**: ブラウザの設定、ポップアップブロック
- **対策**:
  - ポップアップを許可する
  - 別のブラウザを試す
  - ページを再読み込みする
