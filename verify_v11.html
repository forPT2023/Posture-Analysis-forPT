🔧 v11.0.0 - 画像と数値データの重複修正

⚠️ ユーザー報告の問題:
Before/After画像と「姿勢改善の数値データ」が重複して表示される
→ 横向き・縦向き両方で発生

🔍 根本原因の特定

問題のコード: 
.comparison-area {
    flex: 1;  /* ← これが原因！ */
    display: flex;
    ...
}

説明:

  • flex: 1 により、.comparison-areaが親要素（.preview-canvas）の利用可能な高さ全体を占有
  • .metrics-areaが下に配置されず、.comparison-areaと重なって表示
  • .preview-canvasはdisplay: flex; flex-direction: columnなので、子要素は縦に並ぶはずだが、flex: 1により.comparison-areaが全高を占有

✅ 実施した修正

修正後のコード: 
.comparison-area {
    flex: 0 0 auto;  /* 内容サイズに応じる */
    display: flex;
    ...
}

効果:

  • .comparison-areaが画像のサイズに応じた高さになる
  • .metrics-areaが.comparison-areaの下に正しく配置される
  • 画像と数値データが重複せず、縦に並ぶ

🧪 検証方法

検証中...

📋 確認手順

  1. 通常リロード（Cmd+R / Ctrl+R）
  2. Before/After画像をアップロード
  3. 「姿勢を分析」ボタンをクリック
  4. 「横向き」「縦向き」両方で確認：
    • ✅ Before/After画像が横並びで表示
    • ✅ 画像の下に「姿勢改善の数値データ」が表示
    • ✅ 画像と数値データが重複していない
