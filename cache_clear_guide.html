キャッシュクリアが必要です

⚠️ 重要
頸部機能評価メニューを表示するには、
スーパーリロード（キャッシュクリア）が必要です

📋 操作手順

ステップ1: 姿勢分析アプリを開く

以下のボタンをクリックして、アプリを開きます。

🚀 姿勢分析アプリを開く

ステップ2: スーパーリロードを実行

以下のキーボードショートカットでスーパーリロードを実行してください：

🍎 Mac

Cmd + Shift + R

または

Cmd + ⌥ Option + R

🪟 Windows / Linux

Ctrl + Shift + R

または

Ctrl + F5

ステップ3: 矢状面（側面）を選択

アプリが再読み込みされたら、「矢状面（側面）」のラジオボタンを選択します。
説明文に「横から撮影（頸部機能評価・前後姿勢分析）」と表示されます。

ステップ4: 矢状面分析設定パネルを確認

矢状面を選択すると、紫色のガイダンスボックスが表示され、
「頸部機能評価」というタイトルとともに、
アライメント評価と後屈可動域測定のオプションが表示されます。

✅ 表示される内容

矢状面分析設定

頸部機能評価
以下のオプションから測定したい項目を選択してください。
✓ アライメント評価: 頭部の前方偏位を測定
✓ 後屈可動域測定: 頸部の伸展角度を測定

💡 ヒント
通常リロード（Cmd+R / Ctrl+R）では、
ブラウザのキャッシュが残るため表示されません。
必ずスーパーリロードを実行してください。

🎯 他の方法でキャッシュをクリアする

Chrome / Edge の場合

1. F12 で開発者ツールを開く
2. ネットワークタブを開く
3. 「キャッシュを無効にする」にチェック
4. 通常リロード（Cmd/Ctrl + R）

Safari の場合

Cmd + ⌥ Option + E でキャッシュを空にしてから、通常リロード

Firefox の場合

Ctrl + Shift + Delete でキャッシュをクリアしてから、通常リロード
