🎯 姿勢分析アプリ v12.0.0 機能検証

📋 実装完了機能

🔍 矢状面分析設定

  • 左右側面の事前選択
  • 撮影側面に応じたランドマーク自動選択
  • 矢状面モードでのみUI表示

📏 アライメント評価モード

  • 耳-肩線と垂直基準線の角度計算
  • 頭部前方偏位距離の測定
  • 正常/軽度/中等度/重度の4段階評価
  • マーカー、測定線、基準線の描画

🔄 後屈可動域測定モード

  • 耳-目線と水平基準線の角度計算
  • 90度を正常可動域として評価
  • 可動域制限度の算出
  • マーカー、測定線、水平基準線の描画

✅ 検証チェックリスト

1. 矢状面モード選択必須
「矢状面（側面）」ラジオボタンを選択 → 「矢状面分析設定」パネルが表示される
2. 撮影側面の選択必須
「左側面」または「右側面」を選択 → 選択した側面に応じてランドマークが自動選択される
3. アライメント評価モード推奨
「アライメント評価」をチェック → 耳と肩にマーカー、耳-肩線（オレンジ）、垂直基準線（緑破線）が表示される
4. 後屈可動域測定モード推奨
「後屈可動域測定」をチェック → 耳と目にマーカー、耳-目線（オレンジ）、水平基準線（緑破線）が表示される
5. 数値データ確認必須
「姿勢を分析」実行後、数値データエリアに以下が表示される：
  • アライメント評価: 頭部前方偏位角度、頭部前方偏位距離、評価ステータス
  • 後屈可動域測定: 頸部後屈可動域、可動域制限度、評価ステータス
  • 改善項目: 「✓ 改善」バッジが表示される
6. 表示オプション推奨
「マーカー表示」「測定線表示」「基準線表示」をON/OFF → リアルタイムで表示が切り替わる

📊 評価基準

アライメント評価モード

0-15° : 正常 15-30° : 軽度前方偏位 30-45° : 中等度前方偏位 45°以上 : 重度前方偏位

後屈可動域測定モード

80-90° : 正常可動域 60-80° : 軽度制限 40-60° : 中等度制限 0-40° : 重度制限

🧪 手動テスト手順

  1. 通常リロード（Cmd+R / Ctrl+R）でページを更新
  2. 「矢状面（側面）」を選択
  3. 「右側面」を選択（または撮影した側面に合わせる）
  4. 「アライメント評価」と「後屈可動域測定」をチェック
  5. Before画像（側面撮影）をアップロード
  6. After画像（側面撮影）をアップロード
  7. 「姿勢を分析」ボタンをクリック
  8. Before/Afterの画像に以下が描画されることを確認：
    • 耳マーカー（金色）
    • 肩マーカー（緑）- アライメント評価
    • 目マーカー（青）- 後屈可動域測定
    • 測定線（オレンジ）
    • 垂直/水平基準線（緑破線）
  9. 数値データエリアで評価結果を確認
  10. 表示オプションをON/OFFして動作確認
